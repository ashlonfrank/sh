# sh — shop.com home page remake

A static HTML/CSS/JS study remake of the [shop.com](https://shop.com/) home page: left rail nav, floating search, category chips, hero carousel, deals and trending store rows, categories, rotating category reel with products, home stores, editorial "Discover" cards, and the footer.

**Unofficial.** This project is not affiliated with Shop or Shopify. Store and product names are fictional, copy is rewritten, and photos are placeholders from picsum.photos.

## Run

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.

## Report

```bash
node report.mjs
```

Checks the remake against the original page's section list and prints `REMAKE COMPLETE` when every check passes.
